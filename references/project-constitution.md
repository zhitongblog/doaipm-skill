# Project taste — say it once, it's remembered

Some preferences you don't want to repeat every time: tech taste, style, constraints, red lines.
Say them once, write them into the project's memory, and the AI follows them from then on.

## The scaffold

```
For this project, always follow:
· Tech taste:   [e.g. use Astro, no heavy frameworks, prefer static where possible]
· Style:        [e.g. dark, restrained, lots of whitespace; copy reads like a human wrote it]
· Constraints:  [e.g. no paid/third-party tracking; mobile-first]
· Red lines:    [e.g. never touch production data; ask me before delete/publish/pay actions]
```

Ask the AI to save this as the project's standing agreement (it knows where to put it — e.g. a
project memory or rules file). **This is effectively a lightweight "constitution" for the
project** — but you don't learn any format; you just speak plainly.

**Why it helps:** once taste is fixed, every high-fidelity result the AI produces is consistent in
style, so you don't keep correcting it — which makes responding to needs even faster.
